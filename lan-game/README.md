# 抓人游戏

一个只用 Python 标准库的双 Mac 局域网联机小游戏。玩家吃光点、答题、获得速度，可进入小世界。左上角有实时排行榜。

## 玩法

- 初始速度：`5`；最小速度：`1`；最大速度：`150`
- 速度换算：每点速度每秒移动 `5` 像素
- `1` 分光点不动
- `2` 到 `10` 分光点会以 `x²` 像素/秒的速度远离玩家；只有进入玩家 `3` 秒可达范围后才开始逃跑
- 答对增加对应速度；答错扣当前速度的 `10%`（四舍五入）
- 每成功吃 `1` 个光点，玩家身体大小增加 `2%`
- 尾长作为统计数值保留（初始为身长 `10%`，每次吃光点额外增长 `4%`），只用于成就判定和排行榜展示，不再绘制拖尾（提升性能）
- 支持光影、体型、速度成就；可在规则面板查看解锁进度
- 断线/刷新页面 `180` 秒内自动重连原角色（分数、速度、体型全保留）；停止响应 `8` 秒后地图上变灰并停止移动
- 排行榜全服可见，包括正在小世界里的玩家（名字旁有 🌍 标记）；离线玩家灰显
- 退出小世界后有 `3` 秒入口冷却，不会被立刻吸回去；传送落点保证在入口判定圈外
- 每名玩家有 `3` 次安全跳过机会；跳过不扣分、不消耗题目
- 小世界按概率出现：
  - 低级：`≤2` 分可直接吃
  - 中级：`≤3` 分可直接吃
  - 高级：`≤4` 分可直接吃
  - 顶级：`≤5` 分可直接吃
- 每个小世界有 10 个题点；全部吃完后小世界消失
- 光点分值 1–10，按幂律分布；每个光点显示分值和题目类型
- 题目为通用题，不依赖教材课文；2 分是十以内加减法，3–8 分对应一到六年级的语/数/英，9–10 分是竞赛题
- 每个难度和学科有 100+ 可生成的不同题目，服务器会避免重复发出同一道题

## 操作

- 移动：`W A S D` 或方向键
- 答题：点击选项，或按 `1` 到 `4`
- 安全跳过：点击按钮，或按 `Q`
- 关闭浏览器标签页即可退出

## 文件

- `server.py`：权威服务器、移动、小世界、碰撞、速度与游戏状态
- `quiz.py`：通用题库生成器和答案校验
- `index.html`：浏览器画面、排行榜、成就、小世界和答题界面
- 排行榜和规则介绍默认收起，可通过右上角按钮展开，不遮挡主画面
