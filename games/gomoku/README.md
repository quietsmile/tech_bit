# 五子棋网页版

纯 HTML/CSS/JS 实现的本地双人对战五子棋，无外部依赖。

## 玩法

1. 用浏览器打开 `index.html`。
2. 黑棋先行，双方轮流点击棋盘空位落子。
3. 先在横、竖、两条斜线任意方向连成五子的一方获胜；棋盘下满则平局。
4. 「悔棋」撤销最近一手；「重新开始」清空棋盘。

## 运行

直接双击打开 `index.html` 即可。也可以在该目录执行：

```bash
python3 -m http.server 8000
```

然后访问 <http://localhost:8000/>。

## 文件

- `index.html`：页面入口
- `style.css`：样式
- `game.js`：游戏逻辑

棋盘为 15 × 15，界面为中文，适配手机和桌面端。
