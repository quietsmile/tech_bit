# 中国象棋（网页版）

纯 HTML/CSS/JavaScript 实现的中国象棋双人对弈游戏，无任何外部依赖。直接用浏览器打开 `index.html` 即可开始游戏。

## 玩法

- 红黑双方在同一浏览器中轮流点击走棋，**红方先行**。
- 点击己方棋子选中，棋盘上绿色圆点为可落子位置；点击目标点完成走子（可吃子）。
- 点击已选中的棋子可取消选择。
- **悔棋**：撤销最近一步（支持连续悔棋，包括终局后）。
- **重新开始**：恢复初始局面。
- 顶部状态栏显示当前行棋方；一方将军时显示"将军！"提示。
- 一方被将死或无合法着法（困毙）时，游戏结束并宣布对方获胜。

## 已实现规则

- 棋盘：9×10 交叉点，含河界（楚河汉界）、双方九宫、炮位/兵卒位标记。
- **车**：直线任意距离，不可越子。
- **马**：走"日"字，受蹩马腿限制。
- **炮**：移动同车；吃子必须隔一个"炮架"。
- **兵/卒**：过河前只能前进；过河后可前进或左右横移，永不后退。
- **将/帅**：九宫内一步直行；**将帅不能照面**（同列无隔子为非法局面）。
- **士/仕**：九宫内沿斜线走一格。
- **象/相**：走"田"字，受塞象眼限制，不可过河。
- 走子后不能使己方被将（含照面视为被将），自动过滤非法走法。
- **将军检测**与**胜负判定**（将死/困毙判负）。

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 入口页面 |
| `styles.css` | 界面样式（SVG 棋盘与棋子外观） |
| `rules.js` | 规则引擎：走法生成、将军/照面检测、胜负判定（无 DOM，可在 Node 中测试） |
| `ui.js` | 界面渲染与对局控制（选子、落子提示、悔棋、重新开始） |
