# 看AI图猜古诗 🖼️📜

纯 HTML/CSS/JS 的小学生古诗猜谜小游戏：每题展示一幅 AI 生成的卡通插画，从 4 个选项中选出正确的诗句。题库含 **100 题 / 100 张插画**，覆盖小学 1–6 年级常见古诗；每局随机选择 **10 关**。无外部 CDN 依赖。

## 年级分组（共 100 题）

| 年级 | 题数 | 代表题目 |
| --- | --- | --- |
| 一年级 | 16 | 咏鹅、静夜思、春晓、悯农、小池、敕勒歌… |
| 二年级 | 16 | 村居、咏柳、登鹳雀楼、望庐山瀑布、山行、望天门山… |
| 三年级 | 17 | 惠崇春江晚景、忆江南、元日、清明、九月九日忆山东兄弟… |
| 四年级 | 17 | 题西林壁、出塞、凉州词、夏日绝句、别董大、望洞庭… |
| 五年级 | 17 | 示儿、题临安邸、枫桥夜泊、从军行、竹石、村晚… |
| 六年级 | 17 | 过故人庄、石灰吟、江南春、西江月·夜行黄沙道中、长歌行… |

完整清单（含诗名、作者、正确诗句、四选项、趣味提示）在 `data/questions.js`，源清单 `data/poems.txt`。正确答案位置在 `game.js` 中**每次展示时随机打乱**，选项唯一。

## 图片生成进度

- 需求：100 张，文件名稳定（`assets/<诗名拼音>.png`，见 poems.txt），**不会覆盖已有资产**。
- 批量生成（断点续跑：已有 png 自动跳过；失败写 `scripts/failed.txt` 并生成 `assets/placeholders/<id>.svg` 占位图，游戏端另有 CSS 占位兜底）：

```bash
cd games/poem-guess
./scripts/generate_images.sh 4   # 参数=并行数
```

- 重新生成单张：删除对应 png 后重跑脚本即可。

当前进度：生成中 / 完成后以 `node scripts/validate.mjs` 输出为准（应显示“已存在图片: 100/100”）。

## 校验

```bash
cd games/poem-guess
node --check game.js && node --check data/questions.js
node scripts/validate.mjs   # 100 题、100 图片路径、每题 4 唯一选项且含唯一正确答案、资源存在
```

## 测试步骤

1. `python3 -m http.server 8080` 后打开 http://localhost:8080（或直接双击 index.html）。
2. 点「开始游戏」，核对：
   - 每局限 10 关，判定后自动进入下一关；
   - 每题插画 + 4 选项，正确位置随机（多次刷新验证）；
   - 答对/答错判定、倒计时 15 秒、连击计分、提示与作者显示正常；
   - 「下一题 / 重新开始 / 全部结果（星级）」正常。
3. 临时改名任一 png，刷新确认出现 CSS 占位图且游戏可继续。
