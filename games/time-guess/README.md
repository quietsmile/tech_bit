# ⏱️ 猜时间闯关

一个三关多人挑战小游戏，比较玩家的综合时间感觉和反应速度。

## 三关规则

1. **猜时间**：默认目标 10 秒，可设置 1–120 秒。玩家不看倒计时，凭感觉停止，误差越小越好。
2. **最快点击**：点击开始后尽快再点击停止，“结束时间 − 开始时间”越短越好。
3. **篮球落地**：篮球从高处落下并弹起，玩家需要在球第一次碰到地面的瞬间点击按钮或按空格。

每名玩家依次完成三关。综合成绩为三关数值相加，越小越好：

```text
综合成绩 = 第1关误差 + 第2关点击用时 + 第3关落地时机误差
```

## 玩法设置

- 支持 1–8 名玩家。
- 可修改第一关目标时间。
- 每次开局每关都会重新随机生成篮球下落节奏。
- 最终按综合成绩排名，并显示每关明细。

无外部依赖，直接打开 `index.html` 或通过任意静态服务器访问。
