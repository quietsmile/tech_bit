# 🎭 身份推理 · 谁是卧底

纯 HTML/CSS/JS 实现的同屏传递身份推理游戏，无任何外部依赖。

## 玩法

1. **设置**：房主输入 4–12 名玩家名（逗号/换行分隔），选择卧底数量、是否加入 1 名「白板」、词语对。
2. **传阅身份**：每人轮流拿同一台设备查看身份，看完立即隐藏交给下一人。
   - 平民：拿到相同词语
   - 卧底：拿到相近词语
   - 白板（可选）：看不到任何词
3. **讨论**：所有存活玩家轮流用一句话描述自己的词语（不能直接说出）。
4. **秘密投票**：存活玩家轮流在同一设备上匿名提名一名疑似卧底；得票最多者淘汰，平票无人淘汰。
5. **胜负**：
   - 卧底全部被淘汰 → 平民获胜
   - 存活卧底 ≥ 存活其他玩家 → 卧底获胜
   - 否则进入下一轮讨论
6. 随时可「重新开始」回到设置页。

## 本地保存

勾选「本地保存玩家名」后，设置会存入浏览器 `localStorage`（仅本机），下次打开自动填入。

## 运行

直接用浏览器打开 `index.html` 即可；或：

```bash
cd games/identity-game
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

桌面与手机浏览器均已适配（响应式布局）。
