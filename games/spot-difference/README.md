# 🔍 找不同大冒险

纯 HTML/CSS/JS 图像找不同联机小游戏，最多 6 人，每个玩家独立进度。

## 联机规则

- 自动进入同一个联机房，最多 6 人。
- 第一位玩家选择总人数；人数满足后游戏自动开始。
- 每个玩家的找不同进度、计分和关卡互相独立。
- 同一个差异点可以被多名玩家分别找到，不会因一人找到而对别人消失。
- 每名玩家可以修改自己的名字。

## 运行

```bash
cd games/spot-difference
python3 -m http.server 8080
# 打开 http://localhost:8080
```

或直接双击 `index.html` 在浏览器中打开。

## 游戏规则

- 每关左右并排显示原图和修改图，共有 **3 处差异**
- 点击任意图中的差异点即可命中，命中 +10 分
- 集齐 3 个差异进入下一关，通关额外 +20 分
- 点错 -2 分
- 每关有限时，超时自动跳到下一关
- 支持 **轮流挑战**（每次操作后换人）和 **抢答积分**（答对换人）两种模式

## 游戏模式

| 模式 | 说明 |
|------|------|
| 轮流挑战 | 每次点击后自动切换到下一位玩家 |
| 抢答积分 | 答对后切换到下一位玩家，答错不换人可继续尝试 |

## 用 codex CLI 生成新图片

本机 CLI 参数等效命令（无 `--yolo` 参数，使用 `--dangerously-bypass-approvals-and-sandbox` 代替）：

```bash
bash scripts/generate-images.sh
```

或手动执行：

```bash
codex exec --dangerously-bypass-approvals-and-sandbox "请在 ./assets/ 下生成4组SVG..."
```

生成后：
1. 将 `assets/` 目录下的 SVG 文件更新到 `game.js` 的 `LEVELS` 数组中
2. 更新每组的 `diffs` 坐标数组
3. 如果使用外链图片而非内嵌 SVG，将 `svg()` / `svgB()` 改为返回 `<img src="assets/levelN-a.svg">` 形式

## 音效说明

内置 Web Audio API 音效：
- 命中：双音上升
- 错误：低频方波
- 通关：四音琶音
- 倒计时最后10秒：滴答声
