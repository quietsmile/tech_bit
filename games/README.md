```text

```

## 启动游戏中心

```bash
cd /Users/huaning/work/tech_bit
python3 games/serve.py
```

默认端口是 `8100`。如需换端口：

```bash
GAMES_PORT=8200 python3 games/serve.py
```

## 新增游戏

1. 在 `games/<game-name>/` 下创建独立游戏，入口必须是 `index.html`。
2. 在 `games/index.html` 的 `.grid` 中添加卡片。
3. 更新本 README。
