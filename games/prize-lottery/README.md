# 🎁 反转盲盒抽奖

多人联机盲盒抽奖小游戏。先看夸张的"包装预告"，再触发随机反转事件（奖品进化、双倍惊喜、隐藏彩蛋、全民安慰奖、幸运大反转），最后揭晓奖品。纯 Python 3.9 标准库后端，零依赖。

## 启动

```bash
cd games/prize-lottery
python3 server.py
```

默认监听 `0.0.0.0:8300`，可用环境变量覆盖：

```bash
PORT=9000 python3 server.py
```

本机访问：http://localhost:8300

## 多台设备联机

1. 运行电脑和玩家的 Mac/手机连接**同一个 Wi-Fi（热点）**。
2. 查看运行电脑的局域网 IP（macOS：系统设置 → Wi-Fi → 详细信息，或终端 `ipconfig getifaddr en0`）。
3. 玩家在浏览器打开 `http://<运行电脑IP>:8300`。

## 玩法

1. **房主**：首页展开"没有房间？点这里当房主"→ 创建房间，获得 4 位房间码。房主可添加/批量导入奖品、重置房间。
2. **玩家**：输入房间码 + 昵称加入。
3. 任意玩家点"开抽！"：先播放夸张的包装动画（约 3.5 秒），随后服务器随机触发一个反转事件并揭晓最终奖品。
4. 中奖记录实时出现在"抽奖历史"里，每人中过的奖品显示在玩家列表。
5. 奖品数量抽完自动从奖池扣减；奖池为空时会提示。

### 批量导入格式

每行一条，末尾可带数量（默认 1）：

```
贴纸大礼包 3
卡牌包 2
免作业券
```

## 数据

房间、玩家、奖品、中奖记录保存在目录内 `data.json`（自动创建），重启服务器不丢失。重置房间会恢复默认奖池并清空玩家和历史。

## 内置默认奖品

贴纸大礼包、卡通橡皮盲盒、卡牌包、可爱笔记本、毛绒挂件、彩笔套装、免作业券、神秘棒棒糖。
