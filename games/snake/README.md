# 贪吃蛇网页游戏

纯 HTML/CSS/JS 实现，无任何外部依赖，直接用浏览器打开 `index.html` 即可游玩。

## 玩法

- **方向键 / WASD**：控制蛇的移动方向（禁止 180 度回头）
- **空格**：暂停 / 继续
- **暂停 / 重新开始按钮**：随时暂停继续或重开一局

## 移动端

- 屏幕下方的**方向按钮**可直接点击
- 也可以在游戏区域**滑动手势**控制方向

## 规则

- 吃到红色食物得 1 分，蛇身变长
- 分数越高，移动速度越快（有上限）
- 撞墙或撞到自己则游戏结束
- 最高分保存在浏览器 `localStorage` 中
