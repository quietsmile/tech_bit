# 迷宫竞速（Maze Race）

局域网在线迷宫竞速游戏，支持单人挑战和多人对战，无任何外部依赖。

## 玩法

- 两名玩家在不同浏览器/电脑加入同一房间，从左上角同时出发，先到右下角 🏁 者赢得该关。
- P1（蓝方）：`W` `A` `S` `D`
- P2（红方）：`↑` `←` `↓` `→`
- 共 3 关，迷宫每关变大；每关胜利 +50 分，金币 +10 分，3 关后总分高者获总冠军。
- 页面顶部实时显示计时与比分；每关结束后弹出结算，可进入下一关或再来一局。

## 道具效果

| 图标 | 名称 | 效果 |
|------|------|------|
| 👟 | 加速鞋 | 拾取者 12 秒内加速；可连续拾取叠加，最多 6 层 |
| 👻 | 穿墙幽灵 | 拾取者 4 秒内可穿越墙壁（仍不能出边界） |
| 🐌 | 减速陷阱 | 对手 6 秒内移动明显变慢 |
| 🪙 | 金币 | 立即 +10 分 |

道具在每关随机刷新，位置随机、种类随机。所有道具对每位玩家独立刷新：A 吃过后，B 仍能吃同一个道具并获得效果。撞墙时有低沉碰撞音，吃道具有提示音，通关有胜利音（WebAudio 实时合成，无音频文件）。

## 运行

方式一：直接双击打开 `index.html`。

方式二（推荐，避免个别浏览器本地限制）：

```bash
cd games/maze-race
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 测试步骤

1. **语法检查**：`node --check game.js && node --check test-maze.js`，无输出即通过。
2. **迷宫连通性自动测试**：`node test-maze.js`，应输出 `连通性测试：600 通过 / 0 失败`（3 关 × 200 次随机生成）。
3. **功能手测**：
   - 打开页面，点「开始比赛」（或按回车），双方同时出发。
   - 按 WASD / 方向键移动，撞墙应听到碰撞声且无法穿过。
   - 吃到道具时听到提示音、顶部出现效果说明；验证加速/减速/穿墙效果。
   - 任一方到达 🏁 后弹出结算，点「进入下一关」继续；打完 3 关验证总冠军结算。
   - 点「重置全部比分」可清零重来。

## 单人模式

首页选择「单人挑战」即可创建一个只有自己的房间；不用等待其他玩家，直接倒计时开始。
